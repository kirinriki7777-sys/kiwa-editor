# 操作の対応表

## 層①の項目と行き先

| 層①の項目 | 行き先 | 理由 |
|---|---|---|
| 新規 | `file.new` | 名前の欄は相対パスと絶対パスを受けるため、場所を選ぶ画面は不要 |
| 開く | `view.drawer` | ファイルツリーから選ぶ。開く入口は1つにする |
| 保存 | `file.save` |  |
| 閉じる | `file.close` |  |
| タブ | `file.newTab` | 切り替えはタブ列から行う |
| 検索・置換 | `search.find` | 既存の検索機能を使う。検索欄はタブ列と本文の間に置く |
| 行ジャンプ | `edit.goto` | パレットの `:` が処理を担い、このコマンドはその画面を開く。実装を二重にしない |
| undo | `edit.undo` |  |
| redo | `edit.redo` |  |
| クリップボード | コマンドにしない | 長押しメニューが担う。コピーと貼り付けを行える |
| 単語・行の選択 | コマンドにしない | 長押しやダブルタップ、選択ハンドルから操作する |
| 行の上下移動 | `edit.moveLineUp` | 下向きは `edit.moveLineDown` |
| smart home | コマンドにしない | Home キー入力時の動作であり、名前から呼ぶコマンドではない |
| インデント | `edit.indent` |  |
| 逆インデント | `edit.outdent` |  |
| コメントのトグル | `edit.comment` |  |
| ファイルツリー | `view.drawer` | 「開く」と同じ入口 |
| 自動インデント | コマンドにしない | 設定で切り替える。字下げは言語定義が担う |
| 括弧の自動閉じ | コマンドにしない | 設定で切り替える。閉じる組は言語定義が担う |

## 層②の項目と行き先

| 層②の項目 | 行き先 | 理由 |
|---|---|---|
| 位置履歴 | `nav.back` / `nav.forward` | 戻るは常設バーに置き、頻繁な操作を1手で行えるようにする。進むはメニューとパレットから使う |
| プロジェクト全体検索 | `search.project` | パレットと同じ位置・同じ形の別画面 |
| マルチカーソル | 入れない | 画面が狭く、効果が限られるため対象外 |
| ブックマーク | 入れない | 画面が狭く、効果が限られる。位置履歴から戻ることもできる |
| 括弧対応ジャンプ | 入れない | 画面が狭く、効果が限られるため対象外 |
| split | 入れない | 画面を分割しても表示領域を広げられないため対象外 |
