# 設定の比較表

`+` は対応あり、`-` は対応なし、`見送り` は対応しない判断を示す。
比較対象すべてに `+` がある項目は共通項目として確認する。見送りの理由は備考に記す。

| 分類 | 項目 | acode | xed | squircle | Kiwa | 備考 |
|---|---|---|---|---|---|---|
| 表示 | フォントサイズ | + | + | + | + |  |
| 表示 | エディタのフォント(書体)選択 | + | + | + | + | 等幅 / ゴシック / 明朝。書体名だけをエンジンへ渡す |
| 表示 | 行番号の表示 | + | + | + | + |  |

| 表示 | フルスクリーン表示 | + | + | + | + |  |
| 表示 | カーソルの行に地を敷く | - | - | - | + | 構文の色と変換中の装飾を見分けるため |
